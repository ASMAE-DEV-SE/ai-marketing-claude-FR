# Liste de Contrôle pour le Lancement Produit

## 8 Semaines avant le Lancement

### Stratégie
- [ ] Définir les objectifs du lancement (objectif de chiffre d'affaires, d'utilisateurs, de notoriété)
- [ ] Identifier les segments d'audience cible pour le lancement
- [ ] Choisir le type de lancement (communiqué de presse, e-mail, réseaux sociaux, publicité payante, partenaires, communauté)
- [ ] Fixer la date et l'heure de lancement
- [ ] Définir les indicateurs de succès et les modalités de suivi

### Produit / Service
- [ ] Le produit est finalisé dans sa version de lancement
- [ ] La page d'atterrissage (landing page) est construite et optimisée
- [ ] La grille tarifaire est arrêtée (prix HT indiqués, mention TVA 20 % standard)
- [ ] Le parcours d'onboarding est testé et validé
- [ ] La documentation d'aide / FAQ est rédigée en français
- [ ] CGV (Conditions Générales de Vente) rédigées et conformes au droit français
- [ ] Politique de retour rédigée (mention du délai légal de rétractation de 14 jours pour les consommateurs européens)
- [ ] Mentions légales complètes sur le site (numéro SIRET, capital social, RCS, directeur de publication)

### Conformité RGPD (obligatoire avant tout lancement)
- [ ] Politique de confidentialité conforme RGPD rédigée et accessible depuis toutes les pages
- [ ] Bannière cookie conforme mise en place (recommandé : IAB TCF 2.0 ou équivalent validé CNIL)
- [ ] Tous les formulaires comportent des cases à cocher de consentement explicite (non pré-cochées)
- [ ] DPO (Délégué à la Protection des Données) identifié si requis (obligatoire dès 250 employés ou traitement à grande échelle)
- [ ] Registre des activités de traitement mis à jour
- [ ] Contrats de sous-traitance signés avec tous les prestataires traitant des données personnelles (hébergeur, CRM, outil e-mail, analytics…)
- [ ] Vérification conformité DSA (Digital Services Act) si applicable (plateformes en ligne actives dans l'UE)

---

## 4 Semaines avant le Lancement

### Contenu
- [ ] Rédiger l'article de blog / l'annonce de lancement
- [ ] Créer la séquence e-mail (amorce, lancement, suivi, clôture)
- [ ] Préparer les publications sur les réseaux sociaux pour la semaine de lancement (toutes plateformes)
- [ ] Enregistrer la vidéo de démonstration produit
- [ ] Créer les visuels et images pour le lancement
- [ ] Rédiger le communiqué de presse ou le pitch média (si applicable)
- [ ] Préparer les traductions si diffusion internationale dans l'UE

### Construction de l'Audience
- [ ] Mettre en place la liste d'attente / page d'accès anticipé
- [ ] Commencer à créer de l'anticipation sur les réseaux sociaux
- [ ] Contacter 10 à 20 utilisateurs bêta potentiels
- [ ] Approcher des partenaires de lancement ou des affiliés potentiels
- [ ] Identifier 5 à 10 influenceurs ou créateurs de contenu pertinents à notifier
- [ ] Contacter les médias spécialisés et journalistes du secteur

### Technique
- [ ] Configurer le suivi analytique sur les pages de lancement (conformément au RGPD : analytics avec consentement ou analytics sans cookies)
- [ ] Tester le parcours de paiement de bout en bout (cartes, virement SEPA, PayPal le cas échéant)
- [ ] Paramétrer les automatisations e-mail
- [ ] Configurer les paramètres UTM pour tous les liens de lancement
- [ ] Tester la charge de l'infrastructure (si applicable)
- [ ] Vérifier l'affichage mobile (plus de 60 % du trafic en France provient du mobile)

---

## 1 Semaine avant le Lancement

### Préparation Finale
- [ ] Envoyer l'e-mail d'amorce à toute la liste
- [ ] Planifier toutes les publications sur les réseaux sociaux
- [ ] Briefer les membres de l'équipe sur le plan de lancement
- [ ] Préparer les réponses au support client pour les questions fréquentes
- [ ] Mettre en place le tableau de bord de lancement (canal Slack dédié, dashboard en temps réel)
- [ ] Tester une dernière fois tous les liens, formulaires et parcours de paiement

### Communauté et Relations Presse
- [ ] Envoyer le communiqué de presse aux journalistes et médias identifiés
- [ ] Préparer les publications et stories du jour J
- [ ] Préparer les réponses aux questions attendues
- [ ] Contacter les soutiens pour une mobilisation le jour du lancement

---

## Jour J

### Matin
- [ ] Envoyer l'e-mail de lancement à toute la liste
- [ ] Publier l'annonce de lancement sur tous les réseaux sociaux
- [ ] Envoyer le communiqué de presse (si applicable)
- [ ] Notifier les partenaires, affiliés et influenceurs
- [ ] Surveiller le tableau de bord analytique

### Tout au Long de la Journée
- [ ] Répondre à chaque commentaire et question dans l'heure
- [ ] Partager les réactions des utilisateurs et les premiers résultats sur les réseaux sociaux
- [ ] Remercier personnellement les premiers clients
- [ ] Surveiller les bugs ou problèmes techniques
- [ ] Publier des mises à jour sur l'engagement et les jalons atteints

### Soir
- [ ] Envoyer l'e-mail de preuve sociale (premiers résultats, témoignages)
- [ ] Remercier la communauté pour son soutien
- [ ] Documenter les enseignements à chaud

---

## Post-Lancement (Semaines 1–2)

### Suivi
- [ ] Envoyer les e-mails de suivi (preuve sociale, FAQ, date limite)
- [ ] Contacter personnellement les plus grands soutiens
- [ ] Collecter et publier les témoignages (avec accord écrit des clients)
- [ ] Créer une étude de cas à partir du meilleur résultat précoce
- [ ] Clôturer l'offre de lancement (si limitée dans le temps)

### Analyse
- [ ] Compiler les indicateurs de lancement vs. objectifs initiaux
- [ ] Identifier les canaux les plus performants
- [ ] Documenter ce qui a fonctionné et ce qui n'a pas fonctionné
- [ ] Planifier la stratégie de contenu post-lancement
- [ ] Fixer les objectifs à 30 et 90 jours sur la base des données du lancement
